> **3行で**
> - 紹介サイトの見た目を、**色料の三原色を少しずらした朱・山吹・群青**と、生成りの紙・墨の文字で作り直す。
> - 雰囲気は「バウハウスのフラット」：●▲■の図形と色面で元気に、本文と手順は静かに読ませて信頼を保つ。

## 今のサイトから変わる所
- 動き：カードの出現に小さな外部スクリプト（1KB 程度）を足す。
- 色：ティール（アプリの ocean テーマ）→ 朱・山吹・群青。ダーク表示はやめる。
- 形：●▲■の図形・群青の帯・主要機能カードの色面を足す。「⚠」の絵文字は▲に。
- 並び：機能 7 枚を「主要 3 つ（大）＋ほか 4 つ（小）」に。トップの最後に群青の帯。
- 文字：見出しの欧文・数字に Outfit。ナビの切り替え幅を 640px → 768px。
- 変えない：ページ・URL・ナビの項目・文言（帯の見出し「ダサいスライドとはもうおさらば。」を除く）・CSP・ロゴ。
