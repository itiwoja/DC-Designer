# 変更レポート：ヘッダーとボタンを作り直す
> 2026-11-01 ｜ 依頼：「ヘッダーをもうちょいかっこよくしたい。ダウンロードボタンと機能を見るボタンもいいんだけどなんか違う」

> **3行で**
> - ヘッダーは画面の上に貼り付き、下の縁を●▲■の 3 色の帯（4px）に。ダウンロードはゴーストに下げ、塗りの青はヒーローの主ボタンだけ。
> - ボタンは全種 丸い形・縁 2px・アイコン付き。ゴーストは白い地にして粒が透けないように。
> - ヒーローの主ボタンから版番号を外し、補足の行の頭へ（スマホで 1 行に収まる）。

## 何が「違う」と感じられたか
| 前 | 理由 |
|---|---|
| 角丸 8px の平らな四角・1px の細い縁 | 手書き風ポップ体と●▲■の雰囲気に対して、ありきたりで固い |
| ゴーストが透明 | 粒が透けて、隣の塗りのボタンに比べて弱い |
| ヘッダーとヒーローに塗りの青が 2 つ | ヒーローの主ボタンと目を取り合う |
| 「Windows 版をダウンロード（v1.0.6）」 | 長く、375px で 2 行に割れる |

## 影響範囲
| 対象 | 変更 |
|---|---|
| トークン | `--radius-button` 8px → 999px。`--border-width-control`・`--header-height`・`--header-stripe` を追加。`--hero-min-height` はヘッダーと帯を引く |
| CMP-002 ヘッダー | sticky・3 色の帯・ロゴ 32px・ナビの hover は丸い色面・ダウンロードはゴースト小 |
| CMP-003 ボタン | 丸・縁 2px・アイコン（`Icon.astro`）・ゴーストは白い地 |
| SEC-001-01 ヒーロー | 主ボタンの文言を短く、版番号は補足の行へ |
| ダウンロードページ・404・コピー | ボタンの形が変わる（丸・縁 2px）。ダウンロードページの主ボタンにアイコン |
| 色・コントラスト | 新しい色はない。ゴーストの地が白になっただけ（群青の文字 5.0:1 以上のまま） |

## 🧭 判断してほしいこと
| # | 種類 | 論点 | おすすめ |
|---|---|---|---|
| R-09 | 好み | 丸い形が強すぎると感じたら | `--radius-button` を 12px 前後に戻す（1 か所で全ボタンが変わる） |
| R-10 | 好み | 3 色の帯が派手なら | `--header-stripe` を 3px に、または 1px の線に戻す |

## 追記：帯を動かす（UI-D-53・MOT-006）
依頼：「このヘッダーのカラフルな線を動かしてほしい」。帯を 2 倍幅の板にして `transform` で左 → 右へ流す（1 画面幅 24 秒・等速・無限）。reduced-motion では止める。速すぎる・気が散ると感じたら `--dur-stripe` を長くする。

## 追記：ヘッダーをすりガラスに（UI-D-54）
依頼：「ヘッダーを半透明で背景透ける感じとかにできる？」。地を白 60%＋`backdrop-filter: blur(12px)` に。トップはヒーローの帯をヘッダーの高さだけ上へ伸ばし（`margin-top` を負に・同じだけ `padding-top`）、粒がヘッダー越しに透ける。`backdrop-filter` が効かないブラウザは白 94% で文字を読みやすく保つ。透けすぎ・ぼけすぎは `--header-bg`・`--header-blur` で調整する。
