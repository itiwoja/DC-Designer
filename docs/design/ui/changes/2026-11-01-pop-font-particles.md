# 変更レポート：見出しを手書き風ポップ体に／ヒーローにマウスを追う粒
> 2026-11-01 ｜ 依頼：「Font をもっとポップで手書き風に。元気な感じ。Google Antigravity の最初の画面のように、マウスに追従してパーティクルが動くのを参考に」

> **3行で**
> - 見出し・ボタン・ロゴ・ナビの書体を Outfit → **Mochiy Pop One**（和文・欧文とも）。本文はそのまま。
> - ヒーローの背景に、マウスの周りに集まる **●▲■ の粒**（MOT-004）。ヒーローだけ。
> - CSP は変えない（フォントは同じオリジンから 1 ファイル、粒は自前の JS と canvas）。

## 決まったこと（ユーザー）
| 項目 | 選んだもの | ほかの候補 |
|---|---|---|
| 書体 | Mochiy Pop One | Yusei Magic（おすすめだった）・Hachi Maru Pop |
| 書体の範囲 | 見出し・ボタン・ロゴ（＋ナビ） | 見出しだけ・本文も全部 |
| 粒の形 | ●▲■ の小さな図形 | 短い線・丸い点 |
| 粒の範囲 | ヒーローの背景だけ | ページ全体 |

## 影響範囲
| 対象 | 変更 |
|---|---|
| `--font-display` | `"Outfit", …` → `"Mochiy Pop One", var(--font-body)` |
| `--weight-display` | 800 → 400（Mochiy は 400 のみ。太字の偽造を防ぐ） |
| CMP-001 ヘッダー・ロゴ、CMP-003 ボタン、見出し全般、CMP-010 版番号 | 書体が変わる |
| SEC-001-01 ヒーロー | 背景に canvas（MOT-004）を追加 |
| 03_tokens / 06_motion / 07_responsive_a11y / 00_brief（UI-D-38〜41）/ README / 02 | 上記に合わせて直した |
| 色・コントラスト | 変更なし（書体だけ。粒は飾りで文字の後ろ） |
