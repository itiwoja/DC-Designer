# 変更レポート：機能をポスター作成とスライド作成の 2 つにする
> 2026-11-01 ｜ 依頼：「機能をポスター作製（PDF、PNG出力）、スライド作成（PPTX出力）の二つにして」

> **3行で**
> - アプリから Instagram 投稿モードを外し、ポスターの書き出しに PDF を足した（ポスターは PDF・PNG、スライドは PPTX）。
> - トップの機能カードを 7 枚から 2 枚（● ポスター作成・▲ スライド作成）にし、「ほかにもできること」（SEC-001-03）を廃止。
> - ヒーローの見出しを「ポスターもスライドも、AIの下書きからレイヤーで仕上げる。」にした。

## 影響範囲
| 対象 | 変更 |
|---|---|
| SEC-001-01 ヒーロー | 見出し（`home.md`）と説明文。説明文に書き出しの形式を入れた。スマホ幅では見出しが 5 行になる |
| SEC-001-02 機能 | 見出し「ポスターとスライドを作る」、カード 2 枚、1024px 以上は 2 列 |
| SEC-001-03 ほかの機能 | 廃止。白地の帯と CMP-007 小の CSS も消した |
| 媒体 | `feature-*` を `feature-poster`・`feature-slides` の 2 つに |
| 見出しの書体 | 新しい漢字（作・成など）はサブセットに入っているので作り直し不要 |
