# 文言の見直し：AI っぽい書き方を直す
> 2026-11-02 ｜ 依頼：「AI生成っぽい文章や構成をなくしながら、サイトに表示する文章を改善したい」｜ 手順：`ui-designer` の文言の見直しモード

> **3行で**
> - 大きく AI っぽい所は少ない。直したいのは、トップの「効率よく」「〜するだけで」と、同じ説明（サインイン・レイヤー・書き出し形式）の繰り返し。
> - 書き直し案は 6 件。トップのヒーロー説明・ページ説明（meta）・3 ステップ・ポスターのカード。事実は足していない。
> - textlint は 1 件。ヒーローの見出し（h1 の中の `<span>` の改行）を太字と取り違えた誤検出で、直す所は無い。

## 直さない所
| 場所 | 理由 |
|---|---|
| ヒーローの見出し「ポスターもスライドも、AIの下書きからレイヤーで仕上げる。」 | 中身を名指ししていて、型に当たらない |
| 群青の帯「ダサいスライドとはもうおさらば。」 | 決めぜりふの型だが、ユーザーが選んだ文言（UI-D-31）。書き手の声として残す |
| スライドのカード | 「アニメーション・台本・発表者ビュー」は別々の機能で、3 つ並べる癖ではない |
| ダウンロード・404・フッター | 手順と事実だけで、型が無い |
| 画像の代替テキスト（`media.json`） | 画像の中の文字をそのまま書いているので、画像と合わせる |
| プライバシー・コード署名ポリシー・更新履歴 | 規約と GitHub のリリースノートが正本。このモードの範囲外 |

## 構成（F）
ヒーロー → 使い方 3 ステップ → 機能 2 枚 → デモ → 動作要件 → 帯。機能が 2 枚で、定番の「特長 3 枚」になっていない。構成は変えない。
同じ説明の重なり（サインイン：ヒーロー・STEP 1・meta、レイヤー：見出し・STEP 2・カード）は C-01〜C-04 で減らす。

- 差し替え後：`npm run build`・`npm test`（71 件）・`npm run test:dist` はすべて成功。文言を確かめるテストは無い。
