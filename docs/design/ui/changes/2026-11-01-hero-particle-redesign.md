# 変更レポート：ヒーローを中央・全画面の粒の演出に作り直す
> 2026-11-01 ｜ 依頼：「ヒーローがパーティクルになったから Redesign して。Antigravity の Web サイト参考」

> **3行で**
> - ヒーローを **中央寄せ・ヘッダーを除いた画面いっぱい** にし、全面に●▲■の粒を敷く。画面画像は帯のすぐ下へ。
> - CSS の大きな●▲■（CMP-006）と入りの動き（MOT-002）は廃止。代わりに **開いた直後に粒が集まって見出しの周りに●▲■を作り、1 秒保ってほどける**（MOT-005・1024px 以上）。
> - 見出しを一段大きく（40〜68px・3 行）、ボタンは主「ダウンロード」＋副「機能を見る」。変えたのはヒーローだけ。

## 🧭 判断してほしいこと
| # | 種類 | 論点 | おすすめ |
|---|---|---|---|
| UI-R-07 | リスク | 形になる演出（約 3.4 秒）が見出しを読む最初の数秒に目を取る | 実画面で長ければ「保つ」1 秒を短くする |
| UI-R-08 | リスク | 粒が最大 450 個。古い PC で重い可能性 | 実機で重ければ 1024px 以上の数を減らす（形の点描が粗くなる） |

## 決まったこと
| 項目 | 選んだもの | ほかの候補 | 決め方 |
|---|---|---|---|
| 範囲 | ヒーローだけ | トップ全体・サイト全体 | ユーザー |

| 大きな●▲■ | 粒が集まって形になる | 消す・残す | ユーザー |
| 粒の見た目 | ●▲■ 三色のまま | 短い線・群青だけ | ユーザー |
| 形の場所 | 見出しの周り 3 か所（● 左上・▲ 右・■ ボタンの左下） | 見出しの後ろに 1 つの構図 | ユーザー |

| ボタン | 主＋ゴースト「機能を見る」 | ダウンロードだけ | ユーザー |
