## 要点
- ヘッダーのナビの切り替えは今の 640px から 768px に揃える。
- 図形はスマホで 60% に縮め、文字にかけない。
- 見出しの段は h1 → h2 → h3。各ページ h1 は 1 つ。
- 図形は飾りなので `aria-hidden`。意味は文字で伝える。

## 詳細

### アクセシビリティ
| 項目 | 仕様 |
|---|---|
| コントラスト | 文字 4.5:1 以上・UI 部品 3:1 以上。朱・山吹を文字に使わない（[使い方の制約](03_tokens.md#使い方の制約)） |
| フォーカス | `:focus-visible` に `--focus-ring`。群青の帯の上は山吹（3.31:1） |
| タップ領域 | ボタン 44px 以上、ナビのリンクも上下の余白で 44px にする |
| 色だけで伝えない | 未署名は文字で書く。▲は飾り。コピーの成功・失敗は文で出す |
| 現在地 | ナビに `aria-current="page"`＋下線 |
| 代替テキスト | 画像は `media.json` の `alt`。図形・ロゴの画像は `alt=""` |
| 動き | [06](06_motion.md) の reduced-motion の行に従う |
| 言語 | `lang="ja"`。Outfit は欧文だけなので和文の読み上げに影響しない |

### フォントの読み込み
| 項目 | 仕様 |
|---|---|
| ファイル | Outfit の可変フォント（太さ 700〜800）を woff2 で、基本ラテン文字・数字・記号だけに絞る（目安 20KB 前後） |
| 置き場所 | サイトと同じオリジン（`site/public/` 配下）。CSP は `default-src 'self'` が `font-src` にも効くので変更不要 |
| ライセンス | OFL 1.1。ライセンス文をフォントと一緒に置く |
| 範囲 | `unicode-range` を基本ラテンに限る。和文の字は最初からシステムフォント |
| 表示 | `font-display: swap`、トップでは先読み（preload）。代わりのフォントとの幅の差は `size-adjust` で小さくしてずれを抑える |
| 上流との関係 | SITE-D-31（Web フォントを読まない）を「欧文の自前配信 1 ファイルだけ許す」に一部変える（UI-D-08・UI-R-01） |

### 表示速度・ずれ（CLS）
- 画像・動画は縦横比を先に決め（CMP-015）、`width`/`height` を持たせる。
- ヒーローの図形は画像の枠の中に絶対配置し、場所を取らない。動きは transform と opacity だけ。
- 図形は CSS のクラスで描く（`style` 属性やインラインの CSS は CSP で止まるので使わない：SITE-D-31）。
- MOT-003 の JS は外部ファイルで 1KB 程度。読み込みを待たずに中身は見える。
