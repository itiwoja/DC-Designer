## 要点
- ヘッダーのナビの切り替えは今の 640px から 768px に揃える。
- ヒーローの粒と●▲■の形は文字の塊（見出し〜ボタン）の外枠＋24px に入れない。1024px 未満では形を作らない（PC だけ：UI-D-45）。
- 見出しの段は h1 → h2 → h3。各ページ h1 は 1 つ。
- 図形は飾りなので `aria-hidden`。意味は文字で伝える。

## 詳細

### アクセシビリティ
| 項目 | 仕様 |
|---|---|
| コントラスト | 文字 4.5:1 以上・UI 部品 3:1 以上。朱・山吹を文字に使わない（[使い方の制約](03_tokens.md#使い方の制約)） |
| フォーカス | `:focus-visible` に `--focus-ring`。群青の帯の上は山吹（3.31:1） |
| タップ領域 | ボタン 44px 以上、ナビのリンクも上下の余白で 44px にする |
| 色だけで伝えない | 未署名は文字で書く。▲は飾り。コピーの成功・失敗は文で出す |
| 現在地 | ナビに `aria-current="page"`＋下線 |
| 代替テキスト | 画像は `media.json` の `alt`。図形・ロゴの画像は `alt=""`。ヒーローの canvas は `aria-hidden="true"`（読み上げない） |
| 動き | [06](06_motion.md) の reduced-motion の行に従う |
| 言語 | `lang="ja"`。書体は読み上げに影響しない |

### フォントの読み込み
| 項目 | 仕様 |
|---|---|
| ファイル | Mochiy Pop One（400）を woff2 で、基本ラテン・かな・記号・原稿に出てくる漢字だけに絞る（約 790 字・92KB。UI-D-39） |
| 置き場所 | サイトと同じオリジン（`site/public/` 配下）。CSP は `default-src 'self'` が `font-src` にも効くので変更不要 |
| ライセンス | OFL 1.1。ライセンス文をフォントと一緒に置く |
| 範囲 | `unicode-range` は付けない。ファイルに無い字だけ本文のシステムフォントで出る |
| 表示 | `font-display: swap`、トップでは先読み（preload） |
| 上流との関係 | SITE-D-31（Web フォントを読まない）を「自前配信 1 ファイルだけ許す」に一部変える（UI-D-38・UI-R-01） |

### 表示速度・ずれ（CLS）
- 画像・動画は縦横比を先に決め（CMP-015）、`width`/`height` を持たせる。
- ヒーローの帯は `--hero-min-height` で高さを先に決める。canvas は帯に絶対配置で敷き、場所を取らない（描き始めてもずれない）。
- 最初の画面で一番大きい要素（LCP）は見出しの文字になる。見出しの書体は先読み済み（上の表）。画面画像は帯の下に回るので `loading="lazy"`・先読みしない（UI-D-49）。
- 粒の JS は外部ファイル。止める条件（画面外・タブが裏）で描くのをやめ、電池と CPU を使わない（[MOT-004](06_motion.md#mot-004)）。
- 図形は CSS のクラスで描く（`style` 属性やインラインの CSS は CSP で止まるので使わない：SITE-D-31）。
- MOT-003 の JS は外部ファイルで 1KB 程度。読み込みを待たずに中身は見える。
