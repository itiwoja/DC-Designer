# SITE-ADR-006：サイトのソースは同じリポジトリの site/ に置く
- 状態：承認 ／ 日付：2026-11-01 ／ 決定者：ユーザー
- 影響する ID：SITE-FR-009, SITE-NFR-008, SITE-D-18

## 状況
サイトのソースをアプリと同じリポジトリに置くか、別にするかを決める必要があった。

## 決定
`itiwoja/DC-Designer` の `site/` に置く。依存はアプリと分ける。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 別リポジトリ | 配信 CI・権限と完全に分かれる | リリースとの連動にリポジトリをまたぐトークンが要る | 連動が難しくなる |

## 影響
- `docs/` のポリシーをそのまま読み込める（SITE-ADR-005）。
- アプリの配布物の許可リスト（既存 ADR-005）に `site/` が入らないことを保つ。
