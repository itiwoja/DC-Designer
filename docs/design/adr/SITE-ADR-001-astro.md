# SITE-ADR-001：サイトは Astro で静的に生成する
- 状態：承認 ／ 日付：2026-11-01 ／ 決定者：ユーザー
- 影響する ID：SITE-FR-001〜008, SITE-FR-011, SITE-NFR-001〜004

## 状況
紹介・ダウンロード用の LP を作る。版情報と更新履歴はビルド時に GitHub API から取り込み、ポリシーは Markdown から作りたい。

## 決定
Astro（静的出力）で作る。閲覧時の JS はコピーボタンの `<script>` 1 本だけにし、島（Islands）は使わない（SITE-D-31）。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 素の HTML/CSS | ビルド不要・最も単純 | 更新履歴を手で書くか、閲覧時に API を叩くことになる | 自動反映（SITE-REQ-004）と両立しにくい |
| Vite + React（アプリと同じ） | 描画部品をデモに流用できる | LP として JS が重い | SITE-NFR-004（JS 30KB）に合わない |

## 影響
- `site/` は独自の `package.json` を持つ（SITE-D-18）。
- Markdown の無害化を Astro の変換に組み込む必要がある。
