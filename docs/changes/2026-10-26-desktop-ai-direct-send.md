# exe版：AI送信確認ダイアログの撤去

2026-10-26、利用者の依頼により「AIへ送信する内容の確認」ウィンドウを撤去。

- AIの送信・生成操作をすると、追加の確認ボタンを押さずに処理が進む。本文のみ・画像付きの両方に適用する。
- mainは送信先、要求形式、画像bytesのハッシュを検証し、workerは一致したpayloadだけを1回送る。
- 操作の取り消し、送信結果の管理、worker終了時の結果不明処理は維持する。
- 専用BrowserWindow・preload・IPCを削除し、配布物から確認画面のpreloadを除外する。

この変更は、従来のEXE-FR-004／EXE-SCR-002とADR-002にある「送信前に専用確認窓で本人が承認する」という条件を置き換える。過去の設計・実装メモにある確認窓の説明は変更前の履歴として扱う。

対象：`desktop/aiConsent.ts`、`desktop/main.ts`、デスクトップビルド・配布物検査、関連テスト。
