# 変更：起動ごとの更新確認とアプリ内ポップアップ（配布方針 v0.1相当 → v0.2、2026-10-25）

> **3行で**：毎回起動時に更新を確認し、新版だけアプリ内で案内する。／ 利用者の同意後にダウンロードし、保存して再起動する。／ 実装・依存追加・CI・公開権限の変更は行わない。

## 🧭 判断してほしいこと

更新操作に新たな未決事項はなし。既存の配信先・公開範囲・コード署名方式は正式配信前に確定・検証が必要。

## 影響範囲

- 要件 → 利用者操作 → 機能 → 画面・IPCの対応は、[詳細設計のトレーサビリティ表](../desktop-update-design.md#トレーサビリティ)に集約した。DB追加は不要。
- 将来の統合対象はElectron main・preload、`src/main.tsx`の通常画面共通UI、`src/editor/useAutoSave.ts`等の保存処理。今回はコードを変更していない。
- 本人だけが配信を承認する条件、ブランチ・タグ・公開CIの条件は維持する。配信停止時・署名検証失敗時もキャッシュだけで適用しない。
- 細かな数値はユーザーの「任せる」回答に基づきD-03で決定。通常終了時の自動適用をしない点は、旧方針からの明示的な変更。
