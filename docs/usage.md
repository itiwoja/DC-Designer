# 使い方

[README に戻る](../README.md)

## 画面

| URL | 画面 |
| --- | --- |
| `/` | **ホーム**。ブリーフを書いて AI に作らせる／白紙・PowerPoint・JSON から始める（作るものは「ポスター」か「スライド」の 2 つから選ぶ）／「続きから編集」／最近の成果物。.pptx / .json はドロップでも開ける |
| `?view=editor` | エディタ（左上の DC-Designer メニュー → 「ホーム」「成果物」で移動） |
| `?view=library` | 成果物の管理 |
| `?view=render` | 描画のみ（サムネイル・確認用） |

ホームの「✨ AI でレイアウトを作る」はブリーフをエディタに渡し（`sessionStorage`）、エディタが開いてサーバーの状態が取れ次第そのまま生成を始める。未サインインのときはブリーフを入れたまま案内だけ出す。

## エディタ操作

- キャンバス上でクリック選択・ドラッグ移動。移動中はキャンバス端・中央や他レイヤーの端・中央にスナップしてガイド線を表示（Alt でスナップ無効）
- 8 方向ハンドルでリサイズ（Shift で比率固定＋文字サイズ連動）、上の丸ハンドルで回転（Shift で 15° 刻み）
- スライドは Ctrl+ホイール / 右下のズームバーで拡大縮小（Ctrl+1 で 100%）。Ctrl+＋/－/0 はアプリ全体の表示の拡大縮小・元に戻す（スライドの縮尺は変わらない）
- 矢印キーで 1px（Shift で 10px）移動 / Delete 削除 / Ctrl+C・V コピー＆貼り付け / Ctrl+D 複製 / Ctrl+] [ 重ね順 / Ctrl+Z・Ctrl+Shift+Z
- レイヤー一覧はドラッグで重ね順変更、ダブルクリックで名前変更。ロック中のレイヤーはキャンバス上でクリックが下のレイヤーに通る
- 右パネルでテキスト・色・画像プロンプト・ポスターへの整列・重ね順を編集、「JSON で編集」で任意のプロパティを変更
- 手持ちの画像ファイル（PNG / JPEG / WebP / GIF）も使える: 「💬 チャット」タブの「画像生成」モード（📎 ボタン）や右パネルの「📁」ボタン、キャンバスへのドロップ（画像やポラロイド・PC・スマホの上なら差し替え）、Ctrl/⌘+V の貼り付け。ファイルは `public/generated/up-*.{ext}` に保存され、spec には `/generated/...` のパスだけが入る
- **PDF・画像の参考添付**: 新規作成の「画像・PDF」、チャットモードの📎ボタン、または左パネルへのドロップで追加。PDFはブラウザ内で各ページを画像化し、順番にプレビューしてAIへ渡す（画像を読めるモデルが必要）。1ファイル20MB、画像・PDFページの合計20枚まで。ページごとに×で外せる。パスワード付きPDFは解除してから添付する。添付はタブ内だけ保持し、再読み込み後は再添付して新しいメッセージを送る。
- **PDFを開いて編集**: ホーム「何を作りますか？」の「PDFを開いて編集」から選ぶか、ホームへPDFをドロップ。1ページはポスター、複数ページはページごとのプロジェクトとして開く（20MB・20ページまで）。通常の横書き文字・単純な枠・罫線・図形・画像はPDFの描画データから個別レイヤーへ変換し、PPTXと同じように選択・移動・サイズ変更できる。Word変換は使わない。フォント・文字幅は元と異なる場合がある。スキャンの文字、クリップや特殊描画など安全に分離できない内容は画像として保持し、読み込み時に案内を表示する。原本PDFは変更しない。以前に背景画像として読み込んだ成果物には反映されないため、ホームから元PDFをもう一度読み込む。
- **複数選択の拡大縮小**: 範囲選択した部品は、選択枠の四隅をドラッグして縦横比・配置・文字サイズを保ったまま拡大縮小できる。Ctrl/⌘+Zで一括取り消し。
- 文字を含むコンポーネント（ピル・QR見出し・アイコン＋テキスト・吹き出し・付箋・ポラロイドのキャプション・チェックリスト）は、右パネルの「〇〇の位置」で文字だけを縦横にずらしたり左/中央/右揃えを変えたりできる（props: `textDx` / `textDy` / `textAlign`、QR は `labelDx` / `labelDy` / `labelAlign`）
- **参考画像の再現**（A4 モードのみ）: 「新規作成」で参考画像を追加し「1 枚目をそのまま再現」にチェックすると、雰囲気の参考ではなく見た目をそのまま写し取る。参考画像は幅 1000px（A4 に近ければ 1000×1414）に縮めて座標 1:1 で渡し、文字は一字一句、色は `#rrggbb` 直接、フォントは `src/fonts.ts` のカタログから字形の近いものを選ばせる。写真・イラストなど図形で描けない部分は、AI が `src: "ref:x,y,w,h"` で範囲を返し、元の解像度の参考画像から切り抜いて取り込む（文字が上に載る部分は切り抜かず生成・近似）。生成後は描画結果を参考画像と見比べて 1 回自動で直す（`/api/reproduce` → `/api/reproduce/refine`）。参考画像は非表示・ロックの「参考画像（比較用）」レイヤーとして残り、「参考画像を重ねる」で半透明に重ねて確認、「見比べて直す」でもう一度修正できる
- 左パネルの「💬 チャット」は ChatGPT と会話しながら修正する。会話は 1 本で続けられ（ポスターを切り替えても続く）、選択中レイヤー・古い会話の要約・直近の会話を文脈として渡し、AI は返答と修正後の spec を返す（相談だけなら変更なし）。返答ごとに「元に戻す」ボタンが付き、変更されたレイヤーは一瞬ハイライトされる。入力欄の「🖼 画像生成」に切り替えると、同じ欄から画像を生成でき、結果もチャットに並ぶ。Enter で送信・Shift+Enter で改行。会話はブラウザに保存される
- チャットの文脈管理: ChatGPT プランは `store:false` で会話をサーバーに残せないため、ブラウザ側で管理する。要約していない発言が 24 件を超えたら、直近 10 件を残して古い方を ChatGPT で要約し、既存の要約にまとめる（ローリング要約。`/api/chat/summarize`）。AI には毎回「要約（好み・決定事項・未対応の依頼・却下された案）＋ 直近の原文（最大 12,000 文字）＋ 現在の PosterSpec」を渡す。ポスターの今の状態は spec 自体が持っているので、会話には意図だけが残っていればよい。要約はチャット上部の「🧠 … 記憶中」で確認でき、「履歴を消去」で履歴と要約をまとめて消せる
- PPTX エディターモードでは、指示の中で別のスライドを番号で指せる（「スライド8の内容をスライド5に反映」「3枚目」「p.2」「前／次／最後のスライド」「表紙」）。言及したスライドの内容も ChatGPT に渡り、書き換え先のスライドを ChatGPT が判断してそのスライドを開いて適用する（参照元は変更しない。Ctrl+Z / 「元に戻す」可）
- **添付ロゴの配置**: 画像を添付して「このロゴを右下に余白を取って配置して」「全スライドの隅に小さく配置して」と依頼できる。添付画像は描き直し・再生成せず原画像を使用し、ロゴは縦横比を保って全体を表示するようAIに指示する。通常の編集・全スライドへの適用・新規スライド追加に対応し、同じタブ内での再送信も元の添付を使う。
- 削除・AI による生成/修正・JSON 読み込みの直後は、通知の「元に戻す」で直前の状態に戻せる。AI 処理と画像生成はキャンセル可能
- `?view=render`（`&theme=night` など）でエディタなしの描画のみ表示

## 成果物の管理

左上の DC-Designer メニュー → 「成果物」（`?view=library`）で、作ったポスターと画像を一覧・管理できる。

- エディタの内容は `data/posters/<id>.json` に自動保存される（入力が止まって 0.8 秒後。DC-Designer メニュー → 「今すぐ保存」または Ctrl/⌘+S ですぐ保存。ブラウザの localStorage にも控えを持つ）。API サーバーに保存できないときは「⚠ 未保存」と出て、復帰後に自動で保存し直す
- 「✨ 新規作成」で AI に作らせたときと JSON を読み込んだときは、**別のポスターとして**保存される（前のポスターは残る。通知の「元に戻す」で元のポスターに戻る）
- **ポスター**タブ: 単体のポスター（プロジェクトに属さないもの）。サムネイル（`?view=render&poster=<id>`）、検索（タイトル・本文）、並び替え、開く・名前変更（タイトルのダブルクリックでも可）・複製・JSON 書き出し・削除、空のポスターの新規作成
- **プロジェクト**タブ: PPTX から読み込んだスライドの束（デッキ）を 1 件として表示する。スライドは 1 枚ずつ `data/posters/` に保存されているが、ここでは表紙＋枚数の 1 枚のカードにまとまり、ポスターの一覧には出ない。開く（編集中のスライドか 1 枚目）・名前変更・複製（スライドごと）・JSON 書き出し（`{ name, slides: [spec…] }`）・「スライド一覧」でカードを広げて各スライドを直接開く・削除（スライドもまとめて消える）
- **画像**タブ: `public/generated/` の画像（AI 生成・取り込み）と、それを使っているポスター。どのポスターからも使われていない画像だけ削除でき、「未使用を削除」でまとめて消せる

API は [開発者向け](./development.md#成果物の-api) を参照。

## PPTX エディターモード

既存の PowerPoint（.pptx）を読み込んで、スライドごとにこのエディタで編集し、PowerPoint に書き戻せる。

- DC-Designer メニュー → 「PowerPoint を開く…」、またはキャンバスへ .pptx をドロップ
- スライド 1 枚 = 成果物（ポスター）1 件として保存され、並び順は `data/decks/<id>.json` に持つ。成果物画面では「プロジェクト」として 1 件にまとまって見える。キャンバスの下にスライド一覧が出て、クリックで切り替え（切り替え前に自動保存）・追加・複製・並べ替え・削除ができる
- 「PPTX で書き出し」（または書き出しメニューの「PowerPoint（全スライド）」）で全スライドを 1 つの .pptx にまとめる。1 枚ずつの書き出しと同じ変換規則（テキストボックスになる条件は「書き出し」節）が適用される
- スライド一覧の「🔤 フォント」で、資料の雰囲気に合うフォントを ChatGPT に提案してもらえる。雰囲気（任意）を入力すると、全スライドの文面をもとに「見出し＋本文」の組み合わせを 3 案出し、実際の文面でプレビューする。選ぶと全スライドに適用される（通知の「元に戻す」で全スライドを戻せる）
  - 候補は `src/fonts.ts` のカタログ（日本語対応の Google Fonts）から選ばれる
  - 未インストールのフォントは適用時に PC へインストールする（PPTX はフォントを埋め込まないため、PowerPoint で同じ見た目にするのに必要）。Windows / WSL はユーザーフォント（`%LOCALAPPDATA%\Microsoft\Windows\Fonts` ＋ HKCU のレジストリ、管理者権限不要）、macOS は `~/Library/Fonts`、Linux は `~/.local/share/fonts/dc-designer`。PowerPoint を開いている場合は再起動すると反映される
  - 適用は各スライドの `themeOverride.fonts`（display / heavy / body）の差し替えで行う。PPTX から読み込んだ固定のフォント名のテキストは、元が装飾系フォントか大きい文字なら見出し（display）、それ以外は本文（body）に置き換わる。手書き（hand）はそのまま
- **アニメーション**（PowerPoint の「開始」効果）: 要素を選ぶとインスペクターに「アニメーション」欄が出る。効果（表示・フェード・浮き上がり・画面外から（スライドイン）・ワイプ・ズーム・スクロール。スライドイン／ワイプ／スクロールは向きも。スライドインは斜め 4 方向も選べる）、開始（クリック時・直前と同時・直前の動作の後）、長さ・遅延（秒）、再生順（▲▼）を設定できる。「再生」でその要素、右上の ▶ でスライド全体の動きをキャンバス上でプレビュー（クリック待ちは自動で進む）。レイヤー一覧には再生順が「▶1」のように出る
  - PPTX 書き出しで、各スライドの `<p:timing>` として書き込まれ、PowerPoint のアニメーションウィンドウでそのまま編集できる（pptxgenjs はアニメーションを書けないため、書き出した後に slide.xml へ差し込む。`src/animation.ts`）
  - **スクロール**（画像レイヤーだけ）: 縦長（横なら横長）の画像を、枠の中で端から端まで流して Web ページをスクロールしているように見せる。画像は枠の幅（横に流すなら高さ）に合わせて敷かれ、トリミングと fit は使わない。PPTX では、画像全体を 1 枚で置いて移動のアニメーションを付け、枠の外にはみ出す部分は「そのレイヤーより下にあるもの」を画像にした帯で隠す（スライドの端までで足りるので、端に接した辺には帯が付かない）。回転している・枠からはみ出していない画像は、代わりにフェードで書き出す。下にあるレイヤーに別のアニメーションがあっても、帯の中では最初から見えている
  - 背景・非表示のレイヤーには付かない。チャットで「見出しから順にフェードインさせて」のように頼むこともできる
- **台本**（スライドのノート）: キャンバスとスライド一覧の間の「台本」欄に、スライドごとに話す内容を書ける（畳むと 1 行目だけ表示。上の縁をドラッグで高さ変更）。読み上げ時間の目安（300 字/分）も出る。入力は Undo の対象
  - PPTX 書き出しで各スライドのノートになり（PowerPoint の発表者ツールで見られる）、PPTX を開くとノートを台本として読み込む
  - スライドショー中は T キー（または操作バーのボタン）で画面下に台本を重ねて出せる（リハーサル用。映している画面にも出る）
- **発表者ビュー**: スライド一覧の「発表者ビュー」または Alt+F5 で、今のスライドから投影し、別ウィンドウに発表者ビューを開く。今のスライド（出し終えた動きまで。「動き 1 / 3」も表示）・次のスライド・台本（文字の大きさを変えられる）・経過時間（一時停止・リセット）・現在時刻を出し、前へ／次へ・スライドへの移動・黒／白画面・終了をどちらのウィンドウからでも操作できる
  - 画面が複数あり、ブラウザが Window Management API に対応していれば、スライドは発表者ビューと別の画面に全画面で映す（初回はブラウザが「ウィンドウの管理」の許可を求める。許可が間に合わず全画面にできなかったときは、スライドのウィンドウを映す画面へ移す）
  - 発表者ビューは React の portal で別ウィンドウに描いている（状態はスライドショー側が持つ）。ウィンドウを閉じてもスライドショーは続き、スライドショーを終えると閉じる。ポップアップがブロックされると開けない
  - チャットで「このスライドの台本を書いて」のように頼むこともできる（AI に見えるのは開いているスライドと、指示で言及したスライドだけ）
- 読み込めるもの: 背景（単色・グラデーション・画像）、マスター/レイアウトの飾り（ロック済みレイヤー）、テキスト（段落の書式ごとに分割・枠幅で折り返し・箇条書き記号）、四角形/角丸/楕円/三角形/矢印などの図形とフリーフォーム、線、画像（トリミング近似）、表、グループ（展開して個別レイヤー化）
- 読み込めないもの: グラフ・SmartArt・EMF/WMF 画像・動画・アニメーションの効果音。アニメーションは「開始」（入場）効果だけ読み、未対応の効果はフェードに寄せる。ノートは文字だけ（書式は捨てる）。1 段落内で文字ごとに異なる書式は、段落の最初の書式にそろう。読み込めなかった要素は通知に件数が出る

API は [開発者向け](./development.md#デッキフォントの-api) を参照。

## 書き出し

| 形式 | 内容 |
| --- | --- |
| SVG | トップレベルの各レイヤーを名前付きグループ（Inkscape/Affinity のレイヤー属性付き）で出力。画像は埋め込み、フォントは、カタログ（`src/fonts.ts`）内のものを Google Fonts から取得できた場合に**使用文字だけのサブセット**として埋め込む。カタログ外や取得に失敗した場合は警告のみで書き出しを続け、閲覧環境のフォントに依存する |
| PDF | ポスターのみ。PNG と同じ A4 300dpi（2480×3508px）の画像を白地に合成し、可逆圧縮で 1 ページに埋め込む（`src/render/pdf.ts`。依存ライブラリなし）。A4 との差が 0.5mm 以内なら A4 ちょうど（210×297mm）のページにする。文字は画像になるので PDF の中では選択・検索できない |
| PNG | A4 なら A4 300dpi ちょうど（縦 2480×3508px）、そうでなければ幅を A4 300dpi に合わせる。解像度（pHYs）を書き込み、書き出し後に実寸が A4 かを知らせる |
| PPTX | 可視のトップレベルのレイヤーが 1 レイヤー = 1 オブジェクトとして、重なり順を保って配置される。可視のトップレベルの text レイヤーのうち、縁取りがなく、`skewX` がなく、fill が文字列（グラデーションでない）のものは編集可能なテキストボックス。それ以外（コンポーネント・グループ内の文字も含む）はレイヤー単位で切り抜いた透過 PNG |
| JSON | 設計図そのもの。読み込みも可 |
