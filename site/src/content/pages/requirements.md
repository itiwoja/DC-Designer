| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（x64） |
| AI でレイアウトを作る・直す | ChatGPT Plus / Pro などのプランでサインインして使います。**ChatGPT 無料プランは使えません。** Windows 版では OpenRouter は使えません。 |
| 画像の生成 | ChatGPT でサインインすると、画像生成用の Codex CLI も自動で準備され、ChatGPT プランの枠で写真・イラストを作れます（ブラウザでのサインインがもう一度あります）。Gemini の API キーや、この PC で動かす ComfyUI でも作れます。どれも使わないときは仮の画像が入るので、自分の画像に差し替えてください。 |
| サインインなしで使えるもの | 白紙からの編集・保存・書き出し |
